# Heart of the Sun v1.0.0

First portfolio release of **太陽之心 Heart of the Sun**, a two-person learning and portfolio project.

- Supabase Auth integration.
- Guest / Member save flow, with optional Guest progress import when no member cloud save exists.
- Cloud Save / Load and checkpoint recovery.
- RLS data isolation for each member’s save.
- Cloudflare Pages deployment.

🎮 [Live Demo](https://sun-main.pages.dev)

AI tools including ChatGPT and Codex assisted development. Team responsibilities and verification context are documented in the README.
